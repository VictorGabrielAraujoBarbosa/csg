# Credits & licences

## Art, UI and sound effects — Kenney

All 3D models, UI elements, interface sounds, impact sounds and RPG audio come from the
[Kenney](https://kenney.nl) asset kits, released under **CC0 1.0 Universal** (public domain):

- Building Kit · Furniture Kit · Food Kit · Retro Urban Kit
- UI Pack · UI Pack Adventure · Game Icons (+ expansion)
- Interface Sounds · Impact Sounds · RPG Audio

CC0 asks for no attribution, but the kits are excellent and this is the least we can do.
Assets are used unmodified; all colouring is done at runtime with material tints.
